# 👟 Sistema de Gerenciamento de Tênis

Aplicação web do tipo SPA (Single Page Application) desenvolvida em React, que permite gerenciar uma coleção de tênis com funcionalidades completas de CRUD (Criar, Ler, Atualizar, Excluir). Os dados são armazenados no LocalStorage do navegador.

## 🧰 Tecnologias Utilizadas

- **React (v17+)**
- **React Hooks**
- **Bootstrap 5**
- **LocalStorage**
- **UUID** (para geração de IDs únicos)
- **JavaScript (ES6+)**
